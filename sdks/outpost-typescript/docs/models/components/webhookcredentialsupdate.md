# WebhookCredentialsUpdate

Partial Webhook credentials for PATCH updates (RFC 7396 merge-patch).

## Example Usage

```typescript
import { WebhookCredentialsUpdate } from "@hookdeck/outpost-sdk/models/components";

let value: WebhookCredentialsUpdate = {
  customHeaders: "{\"X-Api-Key\":\"new-key\",\"X-Old-Key\":null}",
};
```
